# Morada Mobile

Aplicativo mobile do Morada, construído com React Native, Expo, TypeScript e Expo Router.

## Comandos

```bash
pnpm install
pnpm --filter @morada/mobile start
pnpm --filter @morada/mobile typecheck
```

## Estrutura inicial

- `src/app`: rotas e layouts do Expo Router
- `src/components`: componentes reutilizáveis
- `src/theme`: tokens visuais

Esta fundação é intencionalmente pequena. Novas bibliotecas e abstrações devem ser adicionadas somente quando um fluxo real do produto exigir.
