# Morada brand assets

Source of truth for the production mark used by the mobile app.

- Official tagline: **Um recomeço, um novo lar.**
- Primary green: `#006853`
- Accent yellow: `#F4B400`
- Deep navy: `#0D1B2B`
- Warm off-white: `#F8F7EF`
- Soft green: `#A7D781`
- Typeface: Manrope

`morada-symbol.svg` is the editable vector source. Raster app assets are derived from this source rather than cropped from the approved brand board.
